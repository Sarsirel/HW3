# HW3
Задание №3 курса Data Science

Выбрать и скачать любой открытый датасет, соответствующий интересам или области обучения.
Создать новую базу данных в системе управления базами данных (например, SQLite, PostgreSQL).
Создать таблицу (или несколько таблиц) в базе данных с различными типами данных (INTEGER, TEXT, DATE), которые требуются для вашего датасета. Импортировать данные из датасета в созданные таблицы.
Написать несколько SQL-запросов для извлечения данных из таблиц базы данных. Использовать условия фильтрации (например, WHERE) для получения нужных данных.
Написать SQL-запросы, использующие агрегатные функции (SUM, AVG, COUNT) для выполнения расчетов по данным таблицы.
Визуализировать данные. Использовать библиотеки Python, такие как Matplotlib или Seaborn, для визуализации данных, извлеченных из базы данных. Построить графики или диаграммы, которые помогут проанализировать и понять данные
